# DEF-001 — Uppercase product search returns no results

## Classification
Deliberately introduced training defect in QA Demo Shop.

## Status
Reproduced; fix awaiting verification.

## Environment
Local Node.js server, Playwright, Chromium.

## Severity
Medium: valid searches can hide available products.
Assessment applies to this practice application.

## Preconditions
The search input no longer converts its value to lowercase.

## Steps to reproduce
1. Open the store.
2. Enter MOUSE in Search products.
3. Observe the product list.

## Expected result
One product appears: Wireless Mouse.
Search must ignore letter case.

## Actual result
Zero product cards appear.

## Automated evidence
Command:
npx playwright test shop.spec.js --project=chromium --grep SEARCH-001

Observed result:
- Uppercase MOUSE: failed; expected 1 product, received 0.
- Lowercase mouse: passed.
- Lowercase mouse with surrounding spaces: passed.

Saved report:
evidence/DEF-001/failing-report/index.html

## Root cause
Product names are converted to lowercase, but the search input is not.
The includes comparison is case-sensitive.

## Proposed fix
Restore toLowerCase() after trim() on the search input.

Pending.
